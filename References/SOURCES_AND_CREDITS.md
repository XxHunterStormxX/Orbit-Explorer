# Sources and Credits

## NASA resources referenced by the project

1. **NASA DONKI (Space Weather Database Of Notifications, Knowledge, Information)** — <https://kauai.ccmc.gsfc.nasa.gov/DONKI/>  
   Referenced by the optional CME Analysis data panel in the game. The panel may display a recent CME analysis speed when the API request succeeds.

2. **NASA Open APIs** — <https://api.nasa.gov/>  
   API documentation and access point for NASA public APIs, including DONKI.

3. **NASA Open Science Data Repository (OSDR)** — <https://osdr.nasa.gov/>  
   Linked as a research resource. The current game does not directly retrieve OSDR data.
