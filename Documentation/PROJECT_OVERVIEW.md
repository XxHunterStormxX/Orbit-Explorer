# Project Overview

## ORbit Explorer: Junior Astronaut Mission Trainer

**Challenge context:** NASA Space Apps Challenge 2026  
**Team:** Orbit Sprint  
**Project type:** Educational browser game / Mars-colony resource-management prototype

## Problem

Space mission planning involves interconnected constraints such as resources, power, time, crew needs and risk. These trade-offs can be difficult to understand through text or static explanations alone.

## Proposed solution

ORbit Explorer turns these ideas into an interactive, simplified Mars-colony management experience. Players manage the fictional Base Ares Planitia, monitor colony resources and respond to changing conditions. Decisions have consequences for the colony's ability to remain operational.

## Intended audience

The presentation describes the experience as suitable for learners approximately 7–12 years old, with an easier Explorer mode and a more demanding Astronaut mode. The prototype is an educational starting point; formal learning outcomes have not yet been measured through user testing.

## Learning approach

The game emphasizes learning through decisions and visible consequences rather than a quiz format. Players encounter resource trade-offs, infrastructure choices, crew requirements and simulated events.

## Core experience

- Monitor colony resources and crew status.
- Balance food, water, oxygen and energy.
- Use science to develop upgrades.
- Expand or improve the base through modules.
- Respond to simulated space-weather and operational events.
- Compare outcomes under different difficulty settings.

## Project status

The current deliverable is a single-page HTML prototype. The game and presentation describe the concept and its intended educational value. Further testing, validation and feature development are future work.
