# Orbit Explorer – BETA 0.27

## Música e jogo param quando você sai
Ao trocar de aba, minimizar o navegador ou bloquear o celular:
- o som para na hora (música e efeitos) e volta quando você retorna;
- o jogo **pausa sozinho** e salva, para a base não morrer enquanto você está fora. Ao voltar, aparece a tela PAUSED; é só tocar para continuar.

## Salvamento de verdade
- O jogo salva sozinho no navegador a cada 5 segundos de jogo, ao voltar para o menu e ao sair da página.
- O menu ganhou **CONTINUE** (aparece só quando existe jogo salvo) e o antigo START virou **NEW GAME**.
- Ao perder (fim de missão), o save é apagado.
- Apertar qualquer tecla no menu continua o jogo salvo (ou começa um novo, se não houver).

## Configurações de verdade
Abrem pelo **SETTINGS** do menu e pelo novo botão de **engrenagem** no topo durante o jogo (o tempo para enquanto estão abertas). Tudo fica guardado no navegador.
- **Dificuldade:** Explorer (fácil) ou Astronaut (normal). Mudar durante o jogo vale na hora.
- **Velocidade do jogo:** **Slow** (1 segundo de jogo a cada 1,5 s), **Normal** e **Fast** (1 segundo de jogo a cada 0,6 s).
- **Som:** música e efeitos sonoros ligam e desligam separados. O botão de som do topo liga/desliga tudo de uma vez.
- **Jogo salvo** (só no menu): mostra quanto tempo a missão salva já durou e permite apagar o save.
