# Orbit Explorer – BETA 0.48 (avisos e ícones mais visíveis)

## Base lotada bem visível
- A **caixa dos astronautas** no topo (ex.: "6/5 · POSTO AVANÇADO") agora **pisca inteira em vermelho** quando a base enche, e não só o número.
- Novo **aviso no mapa**, no mesmo estilo do de radiação:
  - **BASE LOTADA** quando todas as vagas estão ocupadas;
  - **SUPERLOTADA!** quando chegam astronautas sem lugar.
- Quando os dois avisos aparecem juntos, o da base fica **embaixo** do de radiação, sem sobrepor.

## Símbolo de radiação
O símbolo ☢ foi redesenhado **com o círculo em volta**, as 3 pás e o centro. Vale para o HUD e para o aviso de radiação alta.

## Ícones dos cliques maiores
Os ícones dos 5 botões de clique (Gelo, Plantas, Oxigênio, Painel Solar e Pesquisar) ficaram **bem maiores**: no computador, a caixa passou de 40 para 64 pixels. Assim fica mais fácil ver qual recurso cada botão dá.

## Outros
O aviso "RADIAÇÃO ALTA" não quebra mais em duas linhas no celular.

## Testes
Prints no computador e no celular com a base superlotada e a radiação alta ao mesmo tempo. **Nenhum erro.**
