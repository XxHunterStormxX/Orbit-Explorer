# Orbit Explorer – BETA 0.26

## Layout para celular
Vale só para telas de até 640px de largura; no computador nada muda. Testado na largura de um iPhone (390px): nada sai para fora da tela.

- **Topo:**
  - A barra de vida ocupa a linha inteira. Embaixo ficam a tripulação e os controles (tempo, pause, som, NASA e menu), que antes ficavam cortados.
  - Os 6 recursos ficam em 3 colunas compactas: ícone colorido, taxa, valor e barra.
- **Base visível:** com o topo e os botões menores, sobra cerca de um terço da tela para ver a colônia. Antes ela não aparecia.
- **Botões de ação:** 3 por linha e mais baixos, sem os rótulos de tecla. O botão do escudo também ficou compacto.
- **Janelas Build, Data e Base:** ocupam quase a largura toda.
- **Sub-abas do Build:** viraram uma faixa só, que rola para o lado.
- **Gráfico da aba Data:** letra menor e mais espaço para os nomes no fim das linhas.
- **Avisos:** o WARNING de evento e o HIGH RADIATION ficaram menores para caber na largura.
