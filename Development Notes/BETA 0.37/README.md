# Orbit Explorer – BETA 0.37

## Todo o texto em pixel art
Antes o jogo misturava a fonte lisa (Andika) com a fonte pixel do título, o que ficava incoerente. Agora **todo o texto é pixel art**: HUD, botões, abas, Build, Skill Tree, Data (inclusive o gráfico), alertas, menu, configurações e abertura.

- **Fonte nova: Tiny5** (Google Fonts). Testei várias fontes pixel. A primeira (Pixelify Sans) deixava o "5" parecido com "S" e o "C" parecido com "O" nos tamanhos pequenos. A Tiny5 foi a mais nítida e fácil de ler para crianças.
- **Letras maiores:** todo o texto cresceu por igual (cerca de 40%), sem mudar o layout de cada tela. No celular a letra cresce um pouco menos, para tudo caber na tela sem rolar para o lado.
- **Títulos:** ORBIT EXPLORER, WARNING, HIGH RADIATION e a abertura continuam na fonte pixel grande (Press Start 2P).
- **Gráfico da aba Data:** os números e nomes das linhas também usam a fonte pixel.
- **Celular:** os nomes dos recursos no topo continuam escondidos (só o ícone colorido), como antes.
