# Orbit Explorer – BETA 0.39

## Novo: TUTORIAL no menu
O menu ganhou a opção **TUTORIAL** (entre NEW GAME e SETTINGS). Ela abre uma janela em pixel art que explica o que cada coisa do jogo faz e como funciona, em inglês simples para crianças.

### Como navegar
- **Abas no topo:** uma por assunto, para pular direto para o que quiser.
- **BACK / NEXT** embaixo, com o contador da página (ex.: 3 / 12). Na última página o botão vira **DONE ✔** e fecha o tutorial.
- **Teclado:** setas ← → trocam a página, Enter avança e Esc fecha.
- Funciona no celular (as abas deslizam para o lado e o texto rola).

### As 12 páginas
| # | Página | O que explica |
|---|---|---|
| 1 | Mission | Objetivo, barra de Health, o jogo nunca fica fácil, quando a vida volta |
| 2 | Resources | Water, Food, Oxygen, Energy, Radiation e Science; o que é o "-0.8/s" |
| 3 | Clicks | Os 5 botões (teclas 1-5): o que cada um dá e quanto custa |
| 4 | Shield | Escudo (tecla 6), gasto de energia, tela verde e aviso HIGH RADIATION |
| 5 | Click upgrades | Aba Click do Build e o Auto Clicker (+15% de gasto por nível) |
| 6 | Skill Tree | Cadeados, galhos, requisitos dos nós e nó piscando quando está pronto |
| 7 | Buildings | Prédios automáticos, Habitat, Storage e upgrade clicando no mapa |
| 8 | Crew | Naves com astronautas e a punição por falta de lugar |
| 9 | Base level | Command Center: +25% de produção por nível, custo e requisitos |
| 10 | Events | Alertas WARNING (inspirados nos dados de clima espacial da NASA) e escolhas |
| 11 | Data | Gráfico, tabela de feito/gasto, lista de eventos e tripulação |
| 12 | Save & keys | Salvamento automático, casinha, pause, dificuldades e teclas |

Cada página tem um ícone pixel colorido, título na fonte do logo e dicas em destaque.
