# Orbit Explorer – BETA 0.29

## Engrenagem removida
O botão de engrenagem (configurações) saiu do topo do jogo. As configurações (dificuldade, som e jogo salvo) ficam só no **SETTINGS** do menu.

## Revisão visual no celular
- **Abas + escudo numa linha só:** antes, Base / Build / Data e o escudo não cabiam juntos e o escudo descia para uma segunda linha, roubando altura do mapa e das janelas. Agora as abas ficaram compactas e o escudo mostra só o ícone, a chave e ON/OFF (o custo continua aparecendo no PC).
- **Gaveta de dados da NASA:** as descrições dos eventos do DONKI podiam ter até 12 linhas cada. Agora são cortadas em 90 letras com "…"; o texto completo continua no link "View NASA record".
- **Configurações:** o botão "COMMANDER" encostava na borda do botão no celular; a letra ficou um pouco menor.
- Conferido na largura de um iPhone (390px): nenhuma tela passa da largura da página.
